Información y requisitos de AutoDrive RD

Aquí encontrarás información sobre cómo está planteada la plataforma, sus herramientas, los requisitos técnicos y los componentes de compra y seguridad. Las funciones de pagos, hosting y facturación mostradas son demostrativas hasta que se conecten los servicios reales.

1

Herramienta de Diseño Web

Desarrollado mediante HTML5 Semántico, Tailwind CSS y JavaScript Moderno (ES6) con arquitectura Single Page Application (SPA), garantizando diseño responsive, experiencia intuitiva y accesibilidad multi-dispositivo.

Frontend Reactivo & Componentizado
2

Host Web (Infraestructura)

Alojamiento optimizado con despliegue de alta disponibilidad en nube CDN de borde (Edge Network), balanceo de carga automático y tiempo de respuesta inferior a 100ms a nivel nacional e internacional.

Cloud Host & CDN Activo
3

Solución de Pago & e-CF DGII

Pasarela de pagos multi-método integrada (Tarjetas PCI-DSS, Transferencias Directas) vinculada directamente con el emisor de Comprobantes Fiscales Electrónicos (e-CF) de la DGII.

PCI-DSS + DGII API v1.2
4

Carrito de Compras / Reserva

Motor de reserva dinámica en tiempo real que bloquea el chasis/VIN seleccionado, gestiona impuestos ITBIS (18%), convierte divisas (DOP/USD) e interactúa dinámicamente con la sesión del usuario.

5

Certificado SSL / TLS Fiable (Capa de Sockets Seguros)

Seguridad Crítica Antifraude

Implementación de cifrado simétrico de 256 bits mediante TLS 1.3 con protocolo HTTPS estricto. Previene el robo de identidades, la interceptación Man-in-the-Middle y garantiza la máxima confianza en el consumidor para evitar el abandono del carrito.
